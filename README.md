Dashboard ini merupakan tampilan visual interaktif yang menampilkan hasil klasifikasi sentimen ulasan pelanggan Mie Gacoan Depok berdasarkan data yang telah diprediksi menggunakan model IndoBERT. \n
Dashboard ini menyajikan informasi penting seperti jumlah ulasan, distribusi sentimen positif dan negatif, tren sentimen dari waktu ke waktu, serta kata kunci dominan yang muncul dalam ulasan. \n
Pengguna dapat memilih cabang tertentu melalui menu dropdown, sehingga visualisasi yang ditampilkan akan menyesuaikan dengan data cabang yang dipilih.
